# 数据与代码放在哪里

两个数据集统一放在 **Sample4Geo/data/**，位于 S4G 项目内部。
所有命令都在 Sample4Geo 根目录执行；路径沿用原项目的相对路径写法。

两个数据集的默认路径是：

```text
./data/U1652/
./data/SUES-200/
```

目录组织如下：

```text
Sample4Geo/
├── data/
│   ├── U1652/
│   │   ├── train/
│   │   │   ├── satellite/地点编号/图像
│   │   │   └── drone/地点编号/图像
│   │   └── test/
│   │       ├── query_drone/地点编号/图像
│   │       ├── gallery_satellite/地点编号/图像
│   │       ├── query_satellite/地点编号/图像
│   │       └── gallery_drone/地点编号/图像
│   └── SUES-200/
│       ├── satellite-view/地点编号/图像          原始数据
│       ├── drone_view_512/地点编号/高度/图像      原始数据
│       ├── Training/高度/{satellite,drone}/地点编号/图像
│       └── Testing/高度/{query_drone,query_satellite,
│                            gallery_drone,gallery_satellite}/地点编号/图像
├── train_university.py
├── eval_university.py
├── train_sues200.py
└── sample4geo/
```

将 U1652 数据放入 U1652/，使它直接包含 train、test。
将 SUES 原始数据放入 SUES-200/，使它直接包含两个原始视角目录。
不要在这两个位置下再多套一层解压包的总文件夹。

Training、Testing 由划分脚本真实复制生成；高度为 150、200、250、300。
训练地点 120 个，测试 query 地点 80 个，gallery 包含全部 200 个地点。

# 安装环境

激活 Python 3.10 环境后，从 Sample4Geo 目录安装：

```bash
python -m pip install -r requirements.txt
```

后续命令也从 Sample4Geo 目录执行。U1652 的配置直接修改
train_university.py、eval_university.py 中的 Configuration；SUES 的配置同样直接修改
train_sues200.py 中的 Configuration。

# 运行 U1652

```bash
python train_university.py
```

默认读取 ./data/U1652/。训练中会评估，结果保存在
Sample4Geo/university/模型名称/运行时间/。

单独评估已有权重时，先将 eval_university.py 中的 checkpoint_start
设置为实际权重文件路径，再运行：

```bash
python eval_university.py
```

# 运行 SUES-200

第一次先准备目录，默认读取 ./data/SUES-200/：

```bash
python sample4geo/dataset/SUES-200/split_datasets.py
```

脚本保留原始数据，在同一个 SUES-200/ 下创建 Training、Testing。
已经整理过的目录无需再运行；脚本不会覆盖已有目标目录。
如果只准备一个高度，可加 --altitudes 150。

train_sues200.py 沿用 train_university.py 的代码结构、变量名和训练流程。
默认配置为 150m、无人机到卫星检索：

```python
dataset: str = 'SUES200-D2S'
data_folder: str = "./data/SUES-200"
altitude: int = 150
model_path: str = "./checkpoints/sues200"
```

训练并在每个 epoch 后评估：

```bash
python train_sues200.py
```

将 Configuration 中的 altitude 改为 200、250、300 即可训练对应高度；
将 dataset 改为 'SUES200-S2D' 即可评估卫星到无人机的检索方向。
两种方向均使用卫星、无人机配对训练，仅测试 query/gallery 的方向不同。

默认 batch size 为 24、训练 1 个 epoch、使用 GPU 0。调整时直接修改配置：

```python
batch_size: int = 24
epochs: int = 1
gpu_ids: tuple = (0,)
```

结果保存在 Sample4Geo/checkpoints/sues200/高度/任务方向/模型名称/运行时间/，
例如 checkpoints/sues200/150/SUES200-D2S/模型名称/运行时间/。
包含 log.txt、train.py、最佳 Recall@1 权重 weights_e*.pth 和最终权重 weights_end.pth。
train.py 是本次训练代码的备份，保留当时的配置。

需要从已有权重开始训练时，在 Configuration 中设置 checkpoint_start。
它只加载模型权重，训练仍从第 1 个 epoch 开始，不恢复优化器和学习率调度器。

gallery 的处理沿用 S4G/CAMP：传入 query_dataset_test.get_sample_ids()，
将非 query 地点的图像标为 -1，评估时排除。磁盘上的 gallery 仍包含 200 地点，
参与排名的是 80 个测试地点；这与完整 200 地点参与排名的口径不同。

# 迁移到 AutoDL

只需将整个 Sample4Geo 文件夹上传到服务器，两个数据集仍放在其 data/ 下。
进入上传后的项目目录，再运行上面的安装和训练命令：

```bash
cd Sample4Geo
```

无需填写本机或服务器的绝对路径，也不依赖同级的其它项目。
需要更换 SUES 数据位置时，同时修改划分脚本的 --path 和训练配置的 data_folder。
结果位置在训练配置的 model_path 中设置。

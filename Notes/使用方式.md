# 数据与代码放在哪里

两个数据集统一放在 **Sample4Geo/data/**，位于 S4G 项目内部。
所有命令都在 Sample4Geo 根目录执行；路径沿用原项目的相对路径写法。

两个数据集的默认路径是：

```text
./data/U1652/
./data/SUES-200/
```

目录组织如下：

```text
Sample4Geo/
├── data/
│   ├── U1652/
│   │   ├── train/
│   │   │   ├── satellite/地点编号/图像
│   │   │   └── drone/地点编号/图像
│   │   └── test/
│   │       ├── query_drone/地点编号/图像
│   │       ├── gallery_satellite/地点编号/图像
│   │       ├── query_satellite/地点编号/图像
│   │       └── gallery_drone/地点编号/图像
│   └── SUES-200/
│       ├── satellite-view/地点编号/图像          原始数据
│       ├── drone_view_512/地点编号/高度/图像      原始数据
│       ├── Training/高度/{satellite,drone}/地点编号/图像
│       └── Testing/高度/{query_drone,query_satellite,
│                            gallery_drone,gallery_satellite}/地点编号/图像
├── train_university.py
├── eval_university.py
├── train_sues200.py
└── sample4geo/
```

将 U1652 数据放入 U1652/，使它直接包含 train、test。
将 SUES 原始数据放入 SUES-200/，使它直接包含两个原始视角目录。
不要在这两个位置下再多套一层解压包的总文件夹。

Training、Testing 由划分脚本真实复制生成；高度为 150、200、250、300。
训练地点 120 个，测试 query 地点 80 个，gallery 包含全部 200 个地点。

# 安装环境

激活 Python 3.10 环境后，从 Sample4Geo 目录安装：

```bash
python -m pip install -r requirements.txt
```

后续命令也从 Sample4Geo 目录执行。三个入口均使用类似 CAMP 的配置方式：
在 Configuration.__init__ 中通过 parser.add_argument 定义参数，
通过 parser.parse_args(namespace=self) 保存，后续仍使用 config.xxx 读取。
不传参数时使用原来的默认值；也可修改各个 add_argument 的 default。

查看某个入口的参数说明和默认值：

```bash
python train_university.py --help
python train_sues200.py --help
python eval_university.py --help
```

# 运行 U1652

```bash
python train_university.py
```

命令行覆盖 batch size、训练轮数、学习率和 GPU 编号：

```bash
python train_university.py --batch_size 24 --epochs 2 --lr 0.001 --gpu_ids 0
```

默认读取 ./data/U1652/。训练中会评估，结果保存在
Sample4Geo/university/模型名称/运行时间/。

单独评估时，通过 checkpoint_start 指定实际权重文件；
eval_university.py 的 batch_size 是评估批量大小：

```bash
python eval_university.py --checkpoint_start ./university/模型名称/运行时间/weights_end.pth --batch_size 128
```

# 运行 SUES-200

第一次先准备目录，默认读取 ./data/SUES-200/：

```bash
python sample4geo/dataset/SUES-200/split_datasets.py
```

脚本保留原始数据，在同一个 SUES-200/ 下创建 Training、Testing。
已经整理过的目录无需再运行；脚本不会覆盖已有目标目录。
如果只准备一个高度，可加 --altitudes 150。

train_sues200.py 沿用 train_university.py 的代码结构、变量名和训练流程。
默认参数为 150m、无人机到卫星检索：

```text
--dataset SUES200-D2S
--data_folder ./data/SUES-200
--altitude 150
--model_path ./checkpoints/sues200
```

训练并在每个 epoch 后评估：

```bash
python train_sues200.py
```

用 --altitude 指定 150、200、250、300，用 --dataset 选择检索方向。
例如训练 300m，并评估卫星到无人机检索：

```bash
python train_sues200.py --altitude 300 --dataset SUES200-S2D --batch_size 24 --epochs 1 --gpu_ids 0
```

两种方向均使用卫星、无人机配对训练，仅测试 query/gallery 的方向不同。

默认 batch size 为 24、训练 1 个 epoch、使用 GPU 0。
batch_size 表示图像对数量，一个 batch 含两种视角各 batch_size 张图像。


结果保存在 Sample4Geo/checkpoints/sues200/高度/任务方向/模型名称/运行时间/，
例如 checkpoints/sues200/150/SUES200-D2S/模型名称/运行时间/。
包含 log.txt、train.py、最佳 Recall@1 权重 weights_e*.pth 和最终权重 weights_end.pth。
train.py 是本次训练代码的备份，保留默认配置；命令行覆盖值需另外记录启动命令。

需要从已有权重开始训练时，通过 --checkpoint_start 指定权重文件。
它只加载模型权重，训练仍从第 1 个 epoch 开始，不恢复优化器和学习率调度器。

gallery 的处理沿用 S4G/CAMP：传入 query_dataset_test.get_sample_ids()，
将非 query 地点的图像标为 -1，评估时排除。磁盘上的 gallery 仍包含 200 地点，
参与排名的是 80 个测试地点；这与完整 200 地点参与排名的口径不同。

# 一次运行全部方向和高度

先安装依赖，按上文准备好 U1652，以及 SUES-200 的全部四个高度。
SUES-200 未划分时先执行（已整理完成则跳过）：

```bash
python sample4geo/dataset/SUES-200/split_datasets.py --path ./data/SUES-200
```

从项目根目录启动批量脚本：

```bash
bash run_all.sh
```

脚本串行完成 10 组独立训练：U1652 的 D2S、S2D，以及 SUES-200
在 150、200、250、300m 下各自的 D2S、S2D。每组沿用训练入口的
自动评估流程，默认每个 epoch 后评估；默认每组训练 1 个 epoch。
两个方向使用相同的配对训练方式，各自独立训练并按对应检索方向评估。

可通过环境变量调整轮数、批量大小和 GPU，例如：

```bash
EPOCHS=2 BATCH_SIZE=16 BATCH_SIZE_EVAL=64 GPU_ID=0 bash run_all.sh
```

也可设置 PYTHON、U1652_DATA、SUES200_DATA、OUTPUT_ROOT；相对路径从
项目根目录计算。默认输出到 checkpoints/all/日期_时间_进程号/，
内部按数据集、方向和高度分目录，并保存每组启动命令、控制台日志及权重。
某组失败时脚本立即停止；再次启动会新建批次，从第一组重新运行。

只查看全部命令、不检查数据目录或启动训练：

```bash
DRY_RUN=1 bash run_all.sh
```

需要关闭终端后继续运行时，可在激活环境并进入项目目录后执行：

```bash
nohup bash run_all.sh > run_all.log 2>&1 &
```

用 `tail -f run_all.log` 查看进度。SUES-200 的 gallery 评估口径仍沿用上文说明。

# 布尔开关和特殊参数

布尔参数使用开关形式，不在后面填写 True 或 False。
正向开关开启，--no- 前缀关闭，例如：

```bash
python train_university.py --no-mixed_precision --no-custom_sampling
python train_sues200.py --zero_shot --no-verbose
```

GPU 编号用空格分隔，解析后仍保存为整数元组，供原有训练代码使用：

```bash
python train_university.py --gpu_ids 0 1
```

使用非默认单卡时，同时指定设备，例如 GPU 1：

```bash
python train_university.py --gpu_ids 1 --device cuda:1
```

训练入口支持 --scheduler none 关闭调度器、--clip_grad None 关闭梯度裁剪。
None 不区分大小写，warmup_epochs 支持 0.1 等小数。

# 迁移到 AutoDL

只需将整个 Sample4Geo 文件夹上传到服务器，两个数据集仍放在其 data/ 下。
进入上传后的项目目录，再运行上面的安装和训练命令：

```bash
cd Sample4Geo
```

无需填写本机或服务器的绝对路径，也不依赖同级的其它项目。
需要更换 SUES 数据位置时，划分脚本的 --path 和训练入口的 --data_folder
应指向同一个 SUES-200 根目录。两个训练入口均可用 --model_path 设置结果根目录。
